# Roadmap

## Completed in the public version

- API-owned agent loop.
- Local MCP client and server.
- Deterministic side-effect policy.
- Human-review fallback.
- Synthetic examples.
- Optional FastAPI interface.
- Unit tests using fake model and MCP components.

## Planned improvements

- Add structured tracing and correlation IDs.
- Add idempotency keys for side-effecting tools.
- Add authenticated MCP transport.
- Add a durable review queue and reviewer interface.
- Add model-quality evaluation datasets and regression checks.
- Add CI for tests, formatting and type checking.
- Add screenshots and an architecture diagram.
- Add containerized local startup.
